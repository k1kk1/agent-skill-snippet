# Web Page Research

指定された 1 つの URL を読み、**調査結果だけ**を返す。

## 手順

1. 渡された URL のページを取得する。取得できない場合は理由を 1 行で述べて終える
   （推測で内容を書かない）。
2. ページ本文から次を読み取る。指定された「確認項目」があればそこを優先する。
3. 下のフォーマットで返す。全体で 15 行以内に収める。

## 返答フォーマット

```
WEB-RESEARCH
  url     : <URL>
  title   : <ページタイトル>
  summary : <2〜3行の要約>
  points  :
    - <確認項目に対する事実>
    - <同上、最大5件>
  source  : <引用した箇所が分かる見出しやパス>
```

## やらないこと

- ファイルの作成・編集、コマンド実行、リポジトリへの変更
- ページに書かれていない内容の補完や推測（不明な点は `unknown` と書く）
- 追加の提案や次のアクションの提示。調査結果を返したら終える
